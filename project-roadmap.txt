TERMINOLOGY
- Features - set of markers and paths on a map
- Marker - visual indicator placed at a specific geographic coordinate on a map to highlight a location
- Sights - a marker attached to a path
- Path - any sequence of connected points on a map
- Circuit path - path that starts and ends at the same point
- Route - specific path to get from point A to point B by Foot/Bike/Car
- Circuit Route - a specific path to get from point A to point B and back to point A by Foot/Bike/Car
- Track - a recorded path of GPS points over time

IMPORT/EXPORT FEATURES
- import map features (support: RontoJSON, GeoJSON, GPX, KML, FIT)
- export map features (support: RontoJSON, GeoJSON, GPX, KML)
- option for import and export map features is in main context menu
- export marker/sight (support: JSON, GeoJSON, GPX, KML)
- export path/track (support: JSON, GeoJSON, GPX, KML, FIT)
1) RontoJSON (.rontojson)
- format like in Firestore database
2) GeoJSON (.geojson)
- marker - Feature with Point geometry
- path - Path (Feature with LineString geometry)
- sight - link them through custom properties like {"pathId": "route-1"}
3) GPX (.gpx)
- marker - Waypoint (<wpt>)
- path - Route (<rte, <rtept>), Track (<trk>, <trkseg>, <trkpt>)
- sight - use naming conventions
4) KML (.kml)
- marker - <Placemark> with a <Point> geometry
- path - <Placemark> with a <LineString>)
- sight - using <MultiGeometry> to link a point and a line inside one Placemark
5) FIT (.fit)
- path - track (a series of records with lat/lon, timestamp, heart rate, speed, cadence, power)

- embedded code - const iframe = `<iframe style="width: 100%; height: 100%; border: none;" allow="fullscreen" scrolling="no" src="<link>"></iframe>`;
    - the copied link always carries &embedded=true&style=<idMapStyle>
- embedded options (opt-in, hand-added to the copied link; only meaningful with &embedded=true)
    &interact=true                              pan/zoom immediately (no activating tap/click first),
                                                alias cursor on hover over markers and finished paths
    &geolocation=true                           show and enable the location control (locate + bearing)
    - NOTE: &geolocation=true also needs the host iframe to delegate the permission, otherwise
      Permissions-Policy blocks navigator.geolocation on any cross-origin site. Edit the snippet to:
      <iframe ... allow="fullscreen; geolocation" ...></iframe>
    - the "Open in RontoMap" logo strips embedded, style, interact and geolocation from the link
- embedded events - posted to the embedding page with window.parent.postMessage({source:"rontomap", type, ...}, "*")
    ready           { styleId }                 the frame takes commands; sent once per frame load, and
                                                with &features_collection only once they are on the map;
                                                styleId is the basemap it opened with
    style-change    { styleId }                 the basemap changed, from the style control or set-style;
                                                only after ready, which already carries the opening style
    marker-click    { marker: {name, description, lng, lat, isSight, index} }
    path-click      { path: {name, description, isCircuit, roadSnap, distance, duration, index, lng, lat} }
- embedded commands - posted by the embedding page with frame.contentWindow.postMessage({source:"rontomap-embed", type, ...}, origin)
    - only in embedded mode, and only from the window that embedded the frame
    - wait for the ready event: commands sent before it are dropped
    set-features    { collectionId }
                    swaps the whole features collection in place, no frame reload — so the
                    camera, the chosen style and everything else on screen survive it
    show-marker     { sightId, zoom, duration }
                    flies to the marker whose description carries that id as JSON
                    ({"id": ...}); does nothing at all if no marker has it
    set-camera      { camera: {lat, long, zoom, bearing, pitch, duration} }
                    flies the map there without reloading the frame; lat/long required,
                    zoom defaults as ?lat/?long does, bearing/pitch/duration keep current/1000ms
